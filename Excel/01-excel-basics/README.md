# Excel Basics Practice

A practical Excel project created while developing my data analysis and spreadsheet skills.

## Skills practiced

- Basic formulas
- IF
- VLOOKUP
- Sorting and filtering
- Percentage calculations
- Pivot tables
- Basic data analysis

## Tools

- Microsoft Excel
- Google Sheets

## Goal

The goal of this project was to practice working with structured data and performing common tasks that may appear in office, data analysis and IT support environments.
