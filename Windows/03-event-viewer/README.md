# Event Viewer Lab

## Goal
Learn how to inspect Windows logs and find system events.

## Tools
- Windows 11
- VirtualBox
- Event Viewer

## Commands / tools used
eventvwr.msc

## What I did
Opened Event Viewer and navigated to:

Windows Logs → System

I inspected an event and identified:

- Level: Information
- Source: Service Control Manager

## What I learned
Event Viewer stores Windows logs that can help troubleshoot system problems.

Information, Warning and Error describe different event levels.
